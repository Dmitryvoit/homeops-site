# HomeOps site

Public information pages for the private HomeOps household operations assistant.

This repository contains only the static public website served at
`https://myhomeops.de`. It intentionally contains no HomeOps application code,
credentials, personal household data, analytics, or tracking scripts.

## Pages

- `/` — application overview and permission summary
- `/privacy.html` — privacy policy and Google user-data disclosure
- `/terms.html` — terms of use

## Hosting

The site is designed for GitHub Pages. The custom domain is declared in `CNAME`.
